# データ記録の手順

感情判定（Calm / Tense / Restless / Groove / Active）の閾値とロジックを、実測データから決めるための記録手順。

## 準備

1. センサーを本番と同じ位置に付ける
   - 心拍センサー（MAX30102）: 指の腹にゴムやマジックテープで軽く固定し、外の光を遮る
   - 加速度センサー（MPU-6050）: 手首（本体側）。向きは毎回同じにする
2. logger スケッチを書き込む

```bash
make upload SKETCH=logger
```

3. 書き込みが終わったら、シリアルモニタは開かずに次の記録へ（ポートを開いているアプリがあると記録できない）

## 記録

1回ごとに `LABEL` で状況名を付ける。ファイルは `data/recordings/<LABEL>-<日時>.csv` に保存され、終わると要約が表示される。

```bash
make record LABEL=calm DURATION=180
```

- 開始から最初の約10秒は心拍が安定しないので、記録を始めてから状況に入ってよい
- 1つの状況につき2回以上記録する（日や時間帯を変えると良い）
- 位置を変えて試したときは `calm-finger2` のようにラベルに付け足す

| LABEL | 想定する感情 | やること | 長さ |
|---|---|---|---|
| `calm` | Calm | 座って腕を膝に置き、静かにしている | 3分 |
| `tense` | Tense | 座ったまま動かずに暗算（1000 から 7 を引き続ける）や、苦手な場面を思い浮かべる | 3分 |
| `restless` | Restless | 座ったまま貧乏ゆすり、指でトントン、ペン回しなど小さく落ち着かない動き | 2分 |
| `groove` | Groove | 好きな曲に合わせて腕や体をリズミカルに揺らす。テンポの違う曲で2回 | 2分 |
| `active` | Active | その場で足踏み、早歩き、腕を大きく振る | 2分 |
| `cooldown` | （Calm へ戻る途中） | `active` や軽い運動（スクワット30回）の直後に座って静止 | 3分 |

`cooldown` は「運動後に心拍が高いまま静止している状態」を Tense と誤判定しないための検証用。

## 記録の確認

```bash
make summary                                    # 全ファイル
make summary FILES="data/recordings/calm-*.csv" # 一部だけ
```

要約で見るところ:

- **約100Hz、50ms超の欠落が0回** — 記録が正常に取れている
- **指あり 90%以上** — 心拍センサーの固定がしっかりしている
- **振り切れ 0行** — 動きが ±8g の範囲に収まっている
- **静止時の1g誤差** — 加速度センサーのずれ。大きければ main で補正が必要

## 記録データ

- CSV の列の意味は `src/logger/logger.ino` の冒頭コメントを参照
- `data/recordings/` は git で管理する（閾値の根拠として残すため）。残したくない場合は `.gitignore` に追加する
